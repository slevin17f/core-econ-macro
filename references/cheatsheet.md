# 决策规则速查 — The Economy 2.0: Macroeconomics

| 能力 | 一句话规则 |
|---|---|
| 工资设定与失业 | 先统一劳动力口径，再用工资与价格设定曲线解释实际工资和就业。 |
| 劳动制度与收入分配 | 追踪制度如何改变工资与岗位，再按收入排序比较分配。 |
| GDP 与需求乘数 | 先列支出恒等式，再说明引致支出怎样反馈到收入。 |
| 通胀与失业 | 给出预期、供给成本与就业的变化路径，区分价格水平和通胀率。 |
| 财政与货币稳定政策 | 明确冲击与政策目标，比较就业和通胀随时间的变化。 |
| 信用与资产负债表 | 逐主体同时记资产和负债，区分结算能力与资本承损能力。 |
| 开放经济的制度约束 | 先识别汇率安排和通胀锚，再追踪资本流动及国内调整。 |
| 临界点与危机 | 写出状态的递推关系，在交点两侧检查反馈和稳定性。 |
| 长期增长与追赶 | 区分增长率与绝对差，把投入贡献与剩余项分别报告。 |
| 政治经济与政策实施 | 将投票激励、行为响应与执行能力分别落实到可验证的环节。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
