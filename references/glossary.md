# 宏观模型术语速查

| 术语 | 解题时怎么用 | 单元 |
|---|---|---|
| 劳动力 labour force | 就业者加失业者。失业率的分母取劳动力，就业率的分母取相应工作年龄人口。 | 1 |
| 实际工资 real wage | 把名义工资除以同基期的价格因子。CPI 以 100 为基期时先除以 100。 | 1 |
| WS / PS | WS 给出各就业水平上企业为招募、留住并激励工人所需支付的实际工资。PS 给出给定生产率与定价下能支付的实际工资。 | 1–2 |
| 洛伦兹曲线 Lorenz curve | 按收入由低到高排，横轴累计人口占比，纵轴累计收入占比。单位可为个人或家庭，比较时统一。 | 2 |
| 自主支出 autonomous spending | 给定模型里与当期收入无关的支出项，改变它会移动总需求线。 | 3 |
| 边际消费倾向 MPC | 每增加一单位可支配收入带来的额外消费。不同家庭的反应可能不同。 | 3、5 |
| 议价缺口 bargaining gap | 给定就业水平上 WS 所需与 PS 可支付的实际工资之间的差距；在预期通胀给定时分析通胀压力。 | 4 |
| 通胀预期锚定 anchored expectations | 暂时价格冲击后，预期仍接近既有锚。分析冲击持续性时须注明预期怎样更新。 | 4–5 |
| 准备金 reserves / 银行资本 equity | 前者是银行在央行的资产，后者是资产减负债的余额。跨行结算和贷款损失分别追踪。 | 6 |
| 货币与汇率制度 | FlexIT 为浮动汇率加稳定通胀目标，FlexNIT 为浮动汇率且缺少稳定目标，Fix 将汇率固定在锚货币上。 | 7 |
| 临界点 tipping point | 状态跨过阈值后，反馈可能把系统带向另一个稳定状态。给出状态量及两边变化方向。 | 8 |
| 杠杆 leverage | 先写比率的分子和分母。用资产/权益时，资产价格变动会放大权益的百分比变化。 | 6、8 |
| 全要素生产率 TFP | 在所选生产函数和投入衡量下未由投入解释的生产效率项。增长核算中以残差估计。 | 9 |
| 中位选民 median voter | 将投票者按单一政策维度排序，找中间位置。在单峰偏好等条件下比较多数票竞争。 | 10 |
| 政治租金 political rents | 政治权力给执政者带来的超出其下一最佳机会的收益。简化模型中可按每期收益与预期任期比较。 | 10 |
