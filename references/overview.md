# CORE Econ 宏观经济学学习地图

The CORE Econ Team (2025), *The Economy 2.0: Macroeconomics*。本技能用中文重构原书的主要分析任务，数值演练与原书案例分别标明。[官方目录](https://books.core-econ.org/the-economy/macroeconomics/0-3-contents.html) · [引用说明](https://books.core-econ.org/the-economy/macroeconomics/0-5-note-to-instructors.html#how-to-cite-the-economy-20-macroeconomics)

从工资与就业出发，第 1–2 单元确定供给侧基准和收入分配。第 3–5 单元引入支出波动、通胀和稳定政策。第 6–8 单元加入资产负债表、国际资本流动与可能失稳的反馈。第 9–10 单元解释长期增长以及政策得以实施的条件。

按问题选课。例如讨论进口能源冲击时先读通胀，再读稳定政策；比较两国政策时补读汇率制度。按节号或题号查找时，在[官方完整目录](https://books.core-econ.org/the-economy/macroeconomics/0-3-contents.html)定位题目，打开相应小节核对数据、图号和模型条件。
